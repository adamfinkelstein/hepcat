# Contributing to Hepcat

Please contact Adam Finkelstein (af@princeton.edu) if you have ideas for how to improve Hepcat and/or want to contribute.

## Development Setup

1. Clone this repository
2. See [README](./README.md) for detailed instructions on how to install and run locally.

## Code Quality

We use several tools to maintain code quality:

- Black for Python formatting
- Flake8 for Python linting
- Prettier for JavaScript/CSS formatting
- ESLint for JavaScript linting

All checks run automatically via pre-commit hooks.

## Pull Requests

1. Create a feature branch from `main`
2. Make your changes
3. Ensure all tests pass
4. Submit a pull request
